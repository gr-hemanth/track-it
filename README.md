## 📊 Track-It

A lightweight and efficient web-based tracking application designed to manage and monitor activities seamlessly. Built with a minimal stack, **Track-It** focuses on simplicity, speed, and usability.

🔗 **Live Demo:**
[https://track-it-gamma-umber.vercel.app](https://track-it-gamma-umber.vercel.app)

---

## 🚀 Features

* 📌 Simple and clean user interface
* ⚡ Fast performance using Vite
* 🗂️ Efficient data tracking and management
* ☁️ Real-time backend with Supabase
* 🔐 Secure data handling

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/track-it.git
cd track-it
```

### 2. Install dependencies

```bash
npm install
```

### 3. Setup environment variables

Create a `.env` file in the root folder:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_KEY=your_publishable_key
```

> Note: Do not commit `.env` file. Ensure it is added in `.gitignore`.

---

### 4. Run development server

```bash
npm run dev
```

### 5. Open in browser

```
http://localhost:5173
```

---

## 🌐 Deployment (Vercel)

1. Push code to GitHub
2. Import repository into Vercel
3. Add environment variables in Vercel settings:

   * `VITE_SUPABASE_URL`
   * `VITE_SUPABASE_KEY`
4. Deploy / Redeploy
